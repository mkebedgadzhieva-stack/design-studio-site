# PAN TERRA — сайт дизайн-студии

**Перед продолжением работы прочитай [PROJECT_STATUS.md](PROJECT_STATUS.md)** — там текущее состояние, проблемы и ближайшие задачи. После законченного этапа обновляй его.

## Цель
Довести сайт студии PAN TERRA (брендинг, айдентика, упаковка, полиграфия) до запуска: публичная часть + личные кабинеты (клиент, администратор, партнёр — партнёрский раздел внутри кабинета).

## Стек и запуск
- Vite 7 + React 19 + react-router-dom 7 + Tailwind CSS 4 (через `@tailwindcss/postcss`) + Supabase (`@supabase/supabase-js`).
- Node 22. Ключи Supabase — в `.env.local` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`), файл не коммитится.
- `npm install` — установка зависимостей
- `npm run dev` — локальный сайт, http://localhost:5173
- `npm run build` — проверка сборки (должна проходить без ошибок)
- `npm run lint` — ESLint

## Структура
- `src/App.jsx` — оболочка сайта (Shell: шапка/футер), главная и простые страницы, все маршруты.
- `src/pages/services/*` — страницы услуг; `src/data/servicesData.js` — каталог услуг для `/services/:slug`.
- `src/features/auth/*` — вход (AuthGate: «Студия» / «Заказчик / партнёр»), Google OAuth, `/auth/callback`.
- `src/cabinet/CabinetLayout.jsx` — кабинет: боковое меню по роли из `profiles.role` (admin / employee / client / partner).
- `src/pages/cabinet/*` — разделы кабинета; `src/ROUTES.md` — карта маршрутов и QA-чеклист.
