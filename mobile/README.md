# PAN TERRA — мобильное приложение (MOB-01)

Отдельное приложение Android/iOS на **React Native + Expo (SDK 58, Expo Router)**. Использует тот же Supabase, что и сайт (только публичный anon-ключ; доступ ограничивает RLS на сервере).

## Что умеет сейчас
Вход заказчика (e-mail и пароль) → «Мои проекты» (этап из 6, статус, срок) → карточка проекта (этапы, следующий шаг, срок). Состояния: загрузка, пусто, ошибка с «Повторить», выход.

Без ключей — **демо-режим**: тестовые проекты «Демо: …» и чёрная плашка «Демо-режим: база не подключена».

## Запуск
```bash
cd mobile
npm install
cp .env.example .env   # вписать те же значения, что VITE_SUPABASE_* у сайта; без этого — демо
npx expo start         # QR-код для приложения Expo Go на телефоне, или w — в браузере
```

## Проверки
```bash
npm test                         # логика этапов и статусов (node:test)
npx expo export --platform web   # сборка веб-версии в dist/
```

## Что проверено (01.11.2026)
- **Только веб-версия** (Chromium, 390×844): вход, список, карточка, назад, выход, неверный пароль, сбой сети и «Повторить», запрос только своих проектов (`client_id`), демо-плашка — 14/14.
- **Android и iOS не проверялись**: в облачной среде нет эмулятора и устройства. iOS-сборка требует macOS.
- `npx expo install` в облаке работает только с `EXPO_OFFLINE=1` (сервер Expo закрыт сетевой политикой).
