# /studio-pause — пауза автопилота

Эту команду запускает только Марьям. Координатор сам паузу не снимает.

1. В `docs/autopilot/STATE.json`: `"paused": true`, `"paused_at"` (ISO-время), `"paused_reason"` (из `$ARGUMENTS` или «по запросу Марьям»). Активную задачу не бросай посреди изменения: доведи до сохранённого состояния или откатись к последнему commit и оставь задачу `ready`.
2. Расписание (см. `docs/autopilot/RUNBOOK.md`, раздел «Расписание»): если в этой сессии доступно управление облачными задачами — отключи задачу с записанным ID (`enabled: false`), не удаляя её. Если недоступно — дай Марьям точные шаги отключения в интерфейсе. Даже без этого фоновый запуск увидит `paused: true` и ничего не будет менять.
3. Commit + обычный push в `claude/studio-autopilot`, чтобы флаг увидели облачные запуски.
4. Скажи Марьям одной-двумя строками, что пауза включена и как её снять (`/studio-resume`).
