# /studio-release — подготовка релиза (без публикации)

1. Прочитай STATE.json, BACKLOG.md, BLOCKERS.md. Перечисли незакрытые `SEC-*` и `FIX-*` с приоритетом P0/P1 — это блокеры релиза.
2. Передай release-engineer: `npm ci`, `npm run lint`, `npm test`, `npm run build`, размер бандла, чеклист `src/ROUTES.md`.
3. Подготовь `docs/release/<версия>.md`: изменения для пользователя, проверки, известные ограничения, откат (предыдущий SHA и шаги).
4. Список действий Марьям: хостинг/домен, переменные окружения, Google OAuth redirect URL, тариф Supabase, применение миграций безопасности.
5. Не публикуй, не мержи в `main`, не трогай рабочую БД — это прямое решение Марьям.
