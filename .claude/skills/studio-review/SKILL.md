# /studio-review — независимая проверка изменений

1. Определи предмет проверки: `$ARGUMENTS` (SHA или диапазон) или `git diff` + `git diff --cached`. Запиши точный SHA/diff — проверяющие не должны смотреть устаревшую копию.
2. Всегда: `npm run lint`, `npm test`, `npm run build`.
3. qa-engineer — если затронуты UI, маршруты, формы, загрузка: сценарии, 390/1440 px, состояния, reduced motion.
4. security-reviewer — если затронуты Auth, RLS, Storage, данные, секреты, зависимости.
5. Верни список замечаний: `[high|medium|low] файл:строка — проблема — как проверить — что исправить`. Без замечаний — перечисли, что просмотрено.
6. Ничего не исправляй сам в рамках этой команды; задачи на исправления добавь в BACKLOG.md.
