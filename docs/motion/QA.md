# Motion QA — фактические результаты

## Прогон 1 — 28.10.2026 (MOTION-01 частично, MOTION-02 механизм)

**Условия:** облачный контейнер Linux; Chromium из предустановленного Playwright, headless; `npx vite` (dev) с `VITE_SUPABASE_URL=http://127.0.0.1:54321` — сеть Supabase подменена через `page.route` (рабочая база не использовалась); размеры 1440×900 и 390×844. Скрипт проверки — вне репозитория (scratchpad сессии); сценарии ниже воспроизводимы на `/dev/motion` вручную.

**Модульные тесты** (`npm test`, `src/motion/delayedFlag.test.js`): 7/7 — порог 500 мс; 100/250/400/499 мс — индикатор не появляется; 1500 мс — появляется на 500 мс и скрывается сразу при готовности; A→B→C без зависшего индикатора; повторный `update(true)` не перезапускает отсчёт; `cancel()` при размонтировании; повторный mount (StrictMode).

| # | Проверка (из задания) | Результат | Как проверено |
| --- | --- | --- | --- |
| 1 | 100–400 мс: индикатора нет; ~1500 мс: после порога и снимается при готовности | **PASS** (превью: 150/400 мс — 0 появлений; 1500 мс — появился на 504 мс, исчез на 1501 мс, содержимое показано). **PASS** (кабинет: роль за ~150 мс — 0 появлений; за ~1500 мс — 1 появление, затем страница) | Playwright, опрос каждые 15–20 мс + MutationObserver |
| 2 | Быстрые кешированные/синхронные страницы — без загрузчика, в т.ч. на медленной сети | **PASS частично**: главная, превью — загрузчика нет; публичные страницы синхронны и загрузчик к смене URL не привязан. Режим throttling сети отдельно не прогонялся | — |
| 3 | Отмена, A → B → C | **PASS** (превью: 1500 → 1500 → 150 мс за 300 мс — 0 появлений, показан результат последнего, старые данные не показаны) | Playwright |
| 4 | Фоновый запрос не включает пантеру; отказ — ошибка и повтор | **PASS** для отказа (превью и кабинет: сеть оборвана → после порога загрузчик, затем `role="alert"` + «Повторить», загрузчика нет). Фоновые запросы к загрузчику не подключены (по коду). «Повторить» в кабинете: после обрыва сети и восстановления — кабинет партнёра загрузился (2 запроса профиля, 0 ошибок JS) | Playwright, `route.abort('internetdisconnected')` |
| 5 | Нет `navigator.connection`, reduced motion | **PASS** (без `navigator.connection` — 0 ошибок JS; reduced motion — `animation-name: none` у мяча) | Playwright `reducedMotion: 'reduce'` |
| 6 | Походка и игра визуально | **НЕ ПРОВЕРЯЕМО** — риг не готов (BLOCKERS B-002). Резервный мяч: 8 кадров с шагом 137 мс — дуга и сжатие видны | Кадры Playwright |
| 7 | 390 px: обрезка, прокрутка, перекрытие, пауза прогулки | **PASS частично**: превью на 390 px без горизонтальной прокрутки. Прогулки ещё нет | Playwright |
| 8 | Нет клетчатого фона; прозрачность, вес, сборка | **PASS** для статичного ассета: PNG RGBA и SVG проверены на шахматном фоне; вес SVG 18,8 КБ / 7,8 КБ gzip. Загрузчик: CSS 2,1 КБ / 1,0 КБ gzip, JS-модули ≈ 2,7 КБ gzip (исходники), CSS в `index.html` 1,1 КБ / 0,7 КБ gzip — бюджет 80 КБ соблюдён. Сборка ок; `/dev/motion` в production-сборку не попадает (поиск по `dist/`) | `gzip -9`, `npm run build` |

**Первое открытие (index.html):** бандл без задержки — загрузчик ни разу не стал видимым (opacity 0); бандл +1500 мс — виден (opacity 1), после старта React заменён. **PASS**.

**FPS** не измерялся: в headless-контейнере без GPU цифра не была бы показательной. Анимация — только `transform`/`opacity`.

## Прогон 3 — 29.10.2026 (MOTION-01: черновой риг и превью сцен)

**Условия:** риг собран `python3 -I tools/motion/build_rig.py` (нарезка силуэта референса на 25 частей, FK/IK, CSS @keyframes); кадры — `node tools/motion/render_preview.cjs` (Chromium, детерминированная перемотка `getAnimations().currentTime`, 25–30 fps), ffmpeg → MP4. Превью переданы Марьям 29.10.2026; на сайт не встроены.

| Проверка | Результат | Оценка |
| --- | --- | --- |
| Узнаваемость в позе референса | **PASS** — нарезка без видимых стыков, силуэт, голова, хвост с завитком, глаза сохранены | — |
| Сцена B: шаг на месте (1400 мс) | **ЧАСТИЧНО** — примерно половина фаз читается как шаг; в фазах сильного выноса задних лап «рвётся» таз (зазубрины, щели), в хвосте видны белые просветы на стыках | 2,5 / 5 |
| Сцена B: проход и опорная стопа | **ЧАСТИЧНО** — IK удерживает подушечку (ошибка ≤ 3,7 px), перемещение согласовано с шагом | — |
| Сцена B: разворот | **FAIL** — в середине разворота тело сжимается в «обрубок», голова и хвост отрываются; нужен рисованный вид спереди/вполоборота | 1 / 5 |
| Сцена A: поза на спине | **ЧАСТИЧНО** — читается как пантера на спине, но голова плохо читается | — |
| Сцена A: лапы ловят мяч | **FAIL** — лапы не дотягиваются до мяча (ошибка IK до 105 px у правой лапы), мяч висит над лапами | 2 / 5 |
| Вес | Загрузчик 93 КБ, шаг 105 КБ (без gzip) — больше бюджета для загрузчика не проверялся, т. к. сцена не принята | — |

**Вывод координатора:** из одного плоского рисунка в профиль сделать качественный разворот и позу «на спине с ловлей мяча» нельзя — нужны дорисованные виды и перекрывающиеся части лап (BLOCKERS B-002). Черновые ассеты лежат в `assets-src/motion/rig/` и на сайт не попадают.
