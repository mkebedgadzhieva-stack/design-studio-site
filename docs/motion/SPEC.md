# Motion SPEC — PAN TERRA

Владелец документа: motion-designer. Версия 0.2 (29.10.2026) — разделы 2 «Итоговая сцена» и 3 уточнены по раскадровке `docs/motion/STORYBOARD.md` (MOTION-01). Версия 0.1 (28.10.2026) — первая редакция координатора.

## 1. Общие правила движения сайта

| Что | Длительность | Кривая | Свойства |
| --- | --- | --- | --- |
| hover / focus (ссылки, кнопки) | 120–160 мс | `ease-out` | `color`, `opacity`, `transform` |
| Появление элемента, загрузчика | 160–200 мс | `ease-out` | `opacity` (+ `translateY` ≤ 8 px) |
| Меню, выпадающие списки | 180–220 мс | `cubic-bezier(.22,1,.36,1)` | `transform`, `opacity` |
| Боковое меню кабинета | 320 мс (существующее) | `cubic-bezier(.22,1,.36,1)` | `width` — оставить как есть |
| Персонаж | отдельные циклы (ниже) | — | `transform`, `opacity` |

- Без бесконечного подпрыгивания интерфейса, перехвата прокрутки, параллакса, мешающего чтению.
- `prefers-reduced-motion: reduce` — интерфейсные переходы мгновенные или только `opacity`; персонаж — статичная поза; текст ожидания остаётся.
- Первый экран главной — статичный (решение Марьям).

## 2. Сцена A — загрузчик

### Условие показа (контракт с кодом)
- `useDelayedPending(pending)` из `src/motion/useDelayedPending.js`, порог `LOADER_DELAY_MS = 500` (`src/motion/delayedFlag.js`).
- `pending` = только критичные для текущего экрана запросы данных и загрузка кода раздела. Не аналитика, не изображения, не фоновые запросы, не открытие меню, не локальные фильтры.
- Готово → содержимое сразу; выход анимации не ждёт конца броска. Ошибка → сообщение + «Повторить». Таймер отменяется при готовности, ошибке, размонтировании.
- Несколько запросов: `pending = a || b` только по необходимым; устаревший запрос отбрасывается (флаг `mounted` / `AbortController`).
- Доступность: обёртка с `aria-busy`, загрузчик `role="status"` + видимый текст; сцена `aria-hidden="true"`; броски не озвучиваются.
- `navigator.connection` не используется (допустим только как необязательная подсказка).

### Резервный вариант (реализован)
`src/motion/PantherLoader.jsx` + `panther-loader.css`: красный мяч (22 px, радиальный градиент) с тенью и подписью.
- Цикл броска 1100 мс; `cubic-bezier(.33,0,.67,1)`.
- Ключевые точки: 0% — на «лапе», сжатие `scale(1.08, .92)`; 12% — уход вверх с вытяжкой `scale(.96,1.04)`; 45–55% — верхняя точка −44 px, пауза (ощущение веса); 88% — разгон вниз; 100% — поимка, сжатие.
- Тень: `scale(1 → .55 → 1)`, `opacity(1 → .45 → 1)` синхронно с высотой.
- Появление 180 мс `opacity`. Reduced motion — без анимации.

### Итоговая сцена (после MOTION-01)
Полная раскадровка, углы и кривые — **`docs/motion/STORYBOARD.md`, раздел 1**. Итоговые числа (L — длина тела, нос → корень хвоста):
- Пантера на спине, голова справа, хвост слева; цикл **2200 мс = 2 броска по 1100 мс**: `fl` гасит и подбрасывает → `fr` ловит, гасит и подбрасывает → `fl` ловит.
- Бросок: 0 мс касание, сжатие `1.08/.92` → 0–60 мс амортизация → 130 мс отрыв (`.96/1.04`, импульс — щелчок кистью) → 495–605 мс зависание → ловящая лапа поднимается за 220 мс и встречает мяч за 120 мс до касания → 1100 мс касание.
- Мяч: вершина на 0,22 L выше точки касания (2 диаметра), смещение по X между лапами 0,08–0,125 L; x — линейно; y — подъём `cubic-bezier(.2,.6,.35,1)`, падение `cubic-bezier(.6,0,.85,.45)`. На лапе мяч привязан к подушечке.
- Корпус: ±2°, синус 2200 мс, крен к ловящей лапе. Задние лапы: ±3° (бедро) в противофазе, пик через 150 мс после отрыва. Хвост: 5 сегментов, сдвиг фазы 80 мс, амплитуды 1–8°. Голова следит за мячом ±6°.
- Главный акцент — мяч; глаза красные, без мигания. Reduced motion — кадр 0 без сжатия (мяч на лапе).

## 3. Сцена B — прогулка у футера (MOTION-03)
- Полоса над футером, высота резервируется заранее: `clamp(96px, 14vw, 160px)`; персонаж по высоте ≤ 80% полосы.
- Путь: от левого поля до правого с отступом = половина длины тела; на телефоне путь = ширина полосы − длина тела.
- Полная раскадровка походки и разворота — **`docs/motion/STORYBOARD.md`, раздел 2**.
- Походка: цикл шага **1400 мс**, боковая последовательность `bl → fl → br → fr` через 350 мс, опора 60% / перенос 40%, на земле всегда 2–3 лапы. Шаг **0,30 L** (уточнено с 0,32 по геометрии лап: подушечка проходит ±0,18 L за опору), полный цикл 0,60 L; скорость = шаг × 2 / 1,4 с = **0,4286 L/с** (≈ 81 px/с при 1440 px, ≈ 48 px/с при 390 px). Фаза и x двигаются от одного множителя темпа k — стопы не скользят; в опоре подушечка закреплена (IK).
- Плечи и таз — вертикаль ±0,012 L (≈ ±2 px при 1440) в противофазе, период 700 мс, плюс поворот ±1°; голова стабилизирована, кивок ±1,5°; хвост — запаздывание 120 мс у корня, +90 мс на каждый сегмент, амплитуды 2–9°.
- Край: замедление k 1 → 0 за 900 мс (`cubic-bezier(.33,0,.67,1)`, ≈ 0,19 L) + 250 мс досадка в стойку; разворот на месте **1200 мс**: голова (scaleX через 0 только у головы, глаза скрыты ≈ 60 мс) → передняя часть (сжатие до 0,45, лапы собираются под центр) → смена стороны под кроссфейдом 80 мс при 4 лапах на земле → таз → хвост; необязательная пауза-«оглядывание» до 400 мс; разгон 900 мс. Без мгновенного зеркалирования и без смены стороны посреди шага.
- Мяч в прогулке не участвует.
- Пауза: IntersectionObserver (полоса вне экрана) и `visibilitychange`; кнопка «Пауза/Продолжить» с `aria-pressed`; пауза — замирание на текущем кадре, продолжение с той же фазы (k 0 → 1 за 300 мс); reduced motion — статичная поза из `public/motion/panther-walk-static.svg`, без кнопки.
- Визуальная приёмка обеих сцен — `docs/motion/STORYBOARD.md`, раздел 6.
- Ассеты прогулки грузятся при приближении футера (`rootMargin: 400px`).
- Не перекрывать ссылки, контакты, кнопки; `pointer-events: none` у персонажа.

## 5. Первое открытие сайта
`index.html` содержит CSS-загрузчик (`.pt-boot`) внутри `#root`: невидим первые 500 мс (`animation-delay`), React заменяет его при первом рендере. Работает без JS-бандла; до получения самого HTML ничего не показывается — это ограничение браузера.
