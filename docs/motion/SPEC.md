# Motion SPEC — PAN TERRA

Владелец документа: motion-designer. Версия 0.1 (28.10.2026) — первая редакция координатора; детальная раскадровка поз — задача MOTION-01.

## 1. Общие правила движения сайта

| Что | Длительность | Кривая | Свойства |
| --- | --- | --- | --- |
| hover / focus (ссылки, кнопки) | 120–160 мс | `ease-out` | `color`, `opacity`, `transform` |
| Появление элемента, загрузчика | 160–200 мс | `ease-out` | `opacity` (+ `translateY` ≤ 8 px) |
| Меню, выпадающие списки | 180–220 мс | `cubic-bezier(.22,1,.36,1)` | `transform`, `opacity` |
| Боковое меню кабинета | 320 мс (существующее) | `cubic-bezier(.22,1,.36,1)` | `width` — оставить как есть |
| Персонаж | отдельные циклы (ниже) | — | `transform`, `opacity` |

- Без бесконечного подпрыгивания интерфейса, перехвата прокрутки, параллакса, мешающего чтению.
- `prefers-reduced-motion: reduce` — интерфейсные переходы мгновенные или только `opacity`; персонаж — статичная поза; текст ожидания остаётся.
- Первый экран главной — статичный (решение Марьям).

## 2. Сцена A — загрузчик

### Условие показа (контракт с кодом)
- `useDelayedPending(pending)` из `src/motion/useDelayedPending.js`, порог `LOADER_DELAY_MS = 500` (`src/motion/delayedFlag.js`).
- `pending` = только критичные для текущего экрана запросы данных и загрузка кода раздела. Не аналитика, не изображения, не фоновые запросы, не открытие меню, не локальные фильтры.
- Готово → содержимое сразу; выход анимации не ждёт конца броска. Ошибка → сообщение + «Повторить». Таймер отменяется при готовности, ошибке, размонтировании.
- Несколько запросов: `pending = a || b` только по необходимым; устаревший запрос отбрасывается (флаг `mounted` / `AbortController`).
- Доступность: обёртка с `aria-busy`, загрузчик `role="status"` + видимый текст; сцена `aria-hidden="true"`; броски не озвучиваются.
- `navigator.connection` не используется (допустим только как необязательная подсказка).

### Резервный вариант (реализован)
`src/motion/PantherLoader.jsx` + `panther-loader.css`: красный мяч (22 px, радиальный градиент) с тенью и подписью.
- Цикл броска 1100 мс; `cubic-bezier(.33,0,.67,1)`.
- Ключевые точки: 0% — на «лапе», сжатие `scale(1.08, .92)`; 12% — уход вверх с вытяжкой `scale(.96,1.04)`; 45–55% — верхняя точка −44 px, пауза (ощущение веса); 88% — разгон вниз; 100% — поимка, сжатие.
- Тень: `scale(1 → .55 → 1)`, `opacity(1 → .45 → 1)` синхронно с высотой.
- Появление 180 мс `opacity`. Reduced motion — без анимации.

### Итоговая сцена (после MOTION-01)
- Пантера на спине, корпус покачивается (±2°, 2200 мс, синус).
- Передние лапы поочерёдно: левая подбрасывает (цикл броска 1100 мс), правая ловит на следующем цикле; лапа выходит навстречу мячу за ~120 мс до контакта.
- Мяч: та же дуга, что в резервном варианте, но со смещением по X между лапами (≈ ширина лапы).
- Задние лапы: лёгкое «подрыгивание» ±3° в противофазе; хвост — волна по 5 сегментам с задержкой 80 мс между сегментами.
- Главный акцент — мяч; глаза красные, без мигания.

## 3. Сцена B — прогулка у футера (MOTION-03)
- Полоса над футером, высота резервируется заранее: `clamp(96px, 14vw, 160px)`; персонаж по высоте ≤ 80% полосы.
- Путь: от левого поля до правого с отступом = половина длины тела; на телефоне путь = ширина полосы − длина тела.
- Походка (после рига): шаг ≈ 0,32 длины тела, цикл шага 1400 мс (вальяжно), скорость перемещения = длина шага × 2 / 1,4 с — стопы не скользят. Плечи и таз — вертикаль ±2 px в противофазе; хвост — запаздывание 120 мс.
- Разворот: замедление на последних 0,5 длины тела (ease-out 600 мс), разворот головы → корпус → таз за 900 мс, без мгновенного зеркалирования посреди шага.
- Пауза: IntersectionObserver (полоса вне экрана) и `visibilitychange`; кнопка «Пауза/Продолжить» с `aria-pressed`; reduced motion — статичная поза из `public/motion/panther-walk-static.svg`.
- Ассеты прогулки грузятся при приближении футера (`rootMargin: 400px`).
- Не перекрывать ссылки, контакты, кнопки; `pointer-events: none` у персонажа.

## 5. Первое открытие сайта
`index.html` содержит CSS-загрузчик (`.pt-boot`) внутри `#root`: невидим первые 500 мс (`animation-delay`), React заменяет его при первом рендере. Работает без JS-бандла; до получения самого HTML ничего не показывается — это ограничение браузера.
