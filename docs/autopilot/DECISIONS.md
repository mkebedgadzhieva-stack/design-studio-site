| D-003 | 28.10.2026 | `/studio-pause` и `/studio-resume` — `disable-model-invocation: true`; `/studio-auto` и `/studio-motion` — доступны модели и расписанию. | Паузу снимает только Марьям; фоновый запуск должен уметь вызвать цикл. |

| D-005 | 28.10.2026 | Загрузчик: собственный хук `useDelayedPending` поверх реального состояния запросов, порог 500 мс; без `useNavigation`/`Suspense` как универсального датчика. | Роутер — `BrowserRouter` + `Routes` (не data router); запросы Supabase идут в `useEffect`, `Suspense` их не видит. |
| D-006 | 28.10.2026 | Первое открытие: CSS-загрузчик прямо в `index.html`, появляется через `animation-delay: 500ms`, React заменяет его при первом рендере. | Работает до загрузки бандла, без JS и внешних ресурсов (~0,7 КБ gzip). До получения самого HTML ничего показать нельзя. |
| D-007 | 28.10.2026 | Пока нет рига, `PantherLoader` показывает резервный вариант из SPEC — красный мяч + текст; пантеру-заглушку как «анимацию» не используем. | Требование задания: не выдавать плоский PNG/неготовый ассет за анимацию. |
| D-008 | 28.10.2026 | Ассеты пантеры извлекаются скриптом `tools/motion/extract_reference.py` (Pillow + numpy + potracer, чистый Python). | D-009 | 28.10.2026 | Тесты — встроенный `node:test` (`npm test`), без новых зависимостей. | Логика порога вынесена в чистый модуль; для неё не нужен jsdom/vitest. |
| D-010 | 28.10.2026 | Браузерные проверки — с заглушкой `VITE_SUPABASE_URL=http://127.0.0.1:54321` и перехватом сети Playwright. | Рабочую базу не трогаем; можно задавать задержки, ошибки и роли. |
