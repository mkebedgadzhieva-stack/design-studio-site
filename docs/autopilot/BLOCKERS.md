## B-001 — Запись проектных разрешений заблокирована
- **Задача:** настройка unattended-режима (раздел 2 автопилот-промпта).
- **Точная причина:** запись `.claude/settings.json` в облачной сессии 28.10.2026 отклонена: «Permission for this action was denied by the Claude Code auto mode classifier. Reason: The server-side auto mode classifier judged this action dangerous (it gave no explanation).»
- **Попытки:** одна — создание `.claude/settings.json` с ограниченным allow-списком и deny для force push, `main`, `.env*` и изменяющих инструментов Supabase. Не обходилось.
- **Контрольный запуск 28.10.2026:** `claude -p "/studio-status" --permission-mode dontAsk --max-turns 12` — завершился за 27 с без зависания; Read/Glob/Grep работали, Bash был отклонён (нет allow-списка), поэтому git-состояние проверялось чтением `.git`. Вывод: для фонового `/studio-auto` через `claude -p` allow-список обязателен.
- **Последствия:** в интерактивной сессии Claude Code будет спрашивать разрешения как обычно; облачное расписание работает по правилам своего окружения. Запуск `claude -p --permission-mode dontAsk` без allow-списка будет отклонять почти все инструменты.
- **Минимальное действие:** Марьям просматривает `docs/autopilot/proposed-settings.json` и, если согласна, копирует блок `permissions` в `.claude/settings.json` (или просит Claude в локальной сессии сделать это — там появится обычный запрос разрешения).

## B-002 — Нет качественного рига пантеры (MOTION-01)
- **Причина:** в среде нет инструментов генерации изображений; референс — одна поза (профиль, шаг, лапа на мяче). Позы «на спине» нет. Разделение лап, головы, хвоста автоматической трассировкой даёт неанатомичные стыки — это было бы «упрощение до неузнаваемости».
- **Сделано:** чистая прозрачная PNG и векторный SVG по слоям (тело, блики, глаза, мяч) — `public/motion/panther-walk-static.svg`, скрипт `tools/motion/extract_reference.py`.
- **Минимальное действие — задание иллюстратору (или Марьям в Illustrator):**
  1. Поза «профиль, ходьба» по референсу: отдельные группы `head`, `neck`, `torso-front` (плечи), `torso-back` (таз), `leg-fl-upper/lower/paw`, `leg-fr-…`, `leg-bl-…`, `leg-br-…`, `tail-1…tail-5`, `eye-left`, `eye-right`. У каждой группы — точка вращения (сустав) отдельным маркером или в имени слоя.
  2. Поза «на спине»: та же пантера лёжа на спине, передние лапы вверх, голова в профиль/три четверти к зрителю, хвост свободно; те же группы + `ball`.
  3. Формат: SVG из Illustrator («Стили: атрибуты презентации», без встроенных растров), заливки `#0B0B0B` (тело) и `#2A2A2A` (блики), глаза и мяч `#E31924`. Положить в `assets-src/motion/rig/`.
  4. Либо покадрово: 12–16 кадров шага и 12–16 кадров броска, PNG с прозрачностью 2× размера показа.
- **Пока:** загрузчик работает с резервным вариантом (мяч + текст), анимация пантеры не объявлена готовой.
